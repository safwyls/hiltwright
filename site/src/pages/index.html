ProffieOS, no code necessary.

Hiltwright configures your Proffieboard saber from the wiring all the way to the firmware install. Pick your presets, styles and sound fonts, and Hiltwright builds the firmware and installs it over USB. No Arduino, C++ or style code necessary.

The install, broken down into five steps.

  1. 1

    Wiring

    Choose the board, the buttons and the prop file, then tell Hiltwright which pins each blade uses. Hiltwright checks the pins (against your installer's config file, if you have one) and writes the config for you.

    How Wiring works
  2. 2

    Fonts

    Pick the sound fonts the saber will carry from your font library, and the voice its menus speak in. Every font gets checked for missing files and misconfiguration.

    How Fonts work
  3. 3

    Presets

    Give each preset a font, a track and a style for each blade, and preview them in the demo room. The list waits in Hiltwright until you flash.

    How Presets work
  4. 4

    Card

    Put the SD card in a card reader and Hiltwright gets it ready in one go: the fonts it's missing, the voice pack, and room for your new preset list. We recommend a card reader, since it's about 30 times faster than the saber's own USB.

    How Card works
  5. 5

    Build & Flash

    One click builds the firmware in about a minute. Hiltwright backs up the saber's existing firmware first, then writes the new one.

    How Build & Flash works

Already flashed? Live changes a plugged-in saber's presets, controls and card at once, with nothing built.

Tweak your blade colors live.

Hiltwright comes with dozens of its own blade styles, each with a live preview, and you can change any of their colors from the Presets page without a rebuild.

Already have a style you like? Paste its code (from the Fett263 style library or anywhere else) and Hiltwright keeps the author's credit in the firmware it builds.

More about styles

Build your own styles, as simple or complex as you like.

Simple mode builds a style from a few blocks: a blade, effects on top, an ignition and a retraction. Full mode opens up every ProffieOS layer, so you decide what each layer shows, where on the blade, and when.

The blade next to the editor updates as you go.

More about the editor

Build and install, with a backup first.

Before Hiltwright writes anything, it reads the saber's whole firmware into a backup file. If you don't like the result, "Put back" restores that backup exactly as you had it.

Hiltwright also downloads and sets up the compiler for you behind the scenes. You never need to open Arduino or read a config file (unless you want to).

More about installing

Coming from Crystal Focus X, Xenopixel or LGT?

No toolchain to set up

ProffieOS normally means figuring out Arduino, board packages, drivers and a config file written in C++. Hiltwright handles all of that for you, so you can focus on your hilt.

Language you understand

The app talks in presets, fonts, colors and effects. Wherever a ProffieOS term comes up, the app explains it in a few words, and the glossary has the full list.

Hard to get wrong

Hiltwright checks the wiring and waits for you to confirm it before anything gets installed. Fonts are checked before they're copied, and any preset change can be undone from History.

Who this beta is for.

Install it now if you're on Windows 10/11 or macOS 13+ and comfortable with the nitty-gritty of saber wiring, installs and configuration. While we're in the early betas, we're focused on hardening Hiltwright's install process and checks so future users won't need to know any of that. Expect things to break, and be comfortable filing issues on GitHub.

Wait for a later release if you aren't comfortable turning off Windows Smart App Control, or you're not sure how your saber is currently wired and configured.

Neither build is signed yet, so Windows and macOS will both warn you before Hiltwright opens, and on Windows, Smart App Control has to be off. macOS is new in this beta: on a Mac, Hiltwright sets up its toolchain and builds firmware, but we haven't confirmed installing to a saber there yet. The install guide walks through all of this step by step.

Whatever you change, the saber's existing firmware is backed up before every install, and "Put back" restores it.
