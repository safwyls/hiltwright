ProffieOS, no code necessary.

Hiltwright configures your Proffieboard saber from the wiring to the firmware install. Choose your presets, styles and sound fonts, then build and install it over USB. No Arduino, C++, or style code needed.

Accurately simulate blade effects.

This is the same simulator Hiltwright uses, running in your browser. It works out what ProffieOS would put on each of 132 LEDs, so you can see a style before it goes near a saber.

Hold Lockup, Drag or Lightning. Click the blade to land a blast. In the app this same blade simulation is available on a 3D hilt you can swing, with your sound font playing. See the demo room.

The install broken down for you, in five steps.

  1. 1

    Wiring

    Choose the board, the buttons and the prop file. Specify which pins each blade uses. Hiltwright checks them, against the installer's config file when you have one, and writes the config.

    How Wiring works
  2. 2

    Fonts

    Choose the sound fonts the saber carries from your font library, and the voice its menus speak in. Every font is checked for missing files and misconfiguration.

    How Fonts work
  3. 3

    Presets

    Give each preset a font, a track and a style for each blade, and preview them in the demo room. The list waits in Hiltwright until the flash.

    How Presets work
  4. 4

    Card

    Put the SD card in a card reader and get it ready in one go: the fonts it lacks, the voice pack, and room for your new preset list. A card reader is about 30 times faster than the saber's own USB.

    How Card works
  5. 5

    Build & Flash

    With a single click you can build the firmware in about a minute. Hiltwright backs up the saber's existing firmware first, then writes the new firmware.

    How Build & Flash works

Already flashed? Live changes a plugged-in saber's presets, controls and card at once, with nothing built.

Modify your blade styles live.

Hiltwright comes with dozens of blade styles of its own, each with a live preview. Every color is editable from the Presets page without requiring a rebuild.

If you already have a style you like, paste its code, from the Fett263 style library or anywhere else, and Hiltwright will maintain the credit when it builds the firmware.

More about styles

Build your own styles, as simple or complex as you like.

Simple mode creates a style from a few building blocks: a blade, effects on top, an ignition and a retraction. Full mode exposes every ProffieOS layer, and you control what every layer does, where on the blade, and when.

The blade next to the editor shows the live style as you modify it.

More about the editor

Backup and restore.

Hiltwright's install process reads the saber's whole firmware into a backup file before it writes anything. "Put back" restores a backup exactly as you had it.

Hiltwright will automatically download and install the necessary compiler behind the scenes. You never need to open Arduino or read a config file, unless you want to.

More about installing

Coming from Crystal Focus X, Xenopixel or LGT?

No toolchain to set up

ProffieOS normally means figuring out Arduino, board packages, drivers and a config file in C++. Hiltwright handles all of that for you, so you can focus on your hilt.

Language you understand

Presets, fonts, colors, effects. Each ProffieOS term is explained in a few words throughout the app, and in the glossary.

Hard to get wrong

Wiring is validated and confirmed before anything is installed, fonts are checked before they are copied, and every preset change can be reverted from the app's History.

Who this beta is for.

Install it now if you are using Windows 10/11 or macOS 13+ and are comfortable with the nitty-gritty of saber wiring, install, and configuration. While we work through the early beta phases we want to focus on hardening Hiltwright's process and validation so future users need not worry about any of that. Be ready for things to break and be comfortable filing issues on GitHub.

Wait for a later release if you aren't comfortable disabling Windows Smart App Control or you're unsure how your saber is wired and configured currently.

Neither build is signed, so both systems will warn you before it opens, and on Windows Smart App Control must be turned off. macOS is new in this beta: on a Mac Hiltwright sets up its toolchain and builds firmware, and installing to a saber has not been confirmed there yet. The install guide covers this step by step.

Whatever you change, the saber's prior firmware is backed up before every install, and "Put back" restores it to your hilt.
