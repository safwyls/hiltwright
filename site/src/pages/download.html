Hiltwright {{version}}

A closed beta for Windows 10 and 11 and for macOS, for a Proffieboard V2.2 or V3. Free and open source.

Get it on GitHub Read the install guide first

For Windows the file is Hiltwright-{{version}}-setup.exe, about 205 MB. It installs for your account only and does not ask for administrator approval.

For a Mac the file is Hiltwright-{{version}}-mac-arm64.dmg (Apple silicon) or Hiltwright-{{version}}-mac-x64.dmg (Intel), about 140 MB. macOS is new in this beta: on a Mac Hiltwright sets up its toolchain and builds firmware, and installing to a saber has not been confirmed there yet. The release notes say how to open it.

On Windows, check Smart App Control first

This beta is not signed. If Smart App Control is On, Windows blocks both the installer and the installed app, and there is no way to allow them. It has to be off while you use this beta.

Look before you download: Windows Security, App & browser control, Smart App Control settings.

What to check, step by step

What you need

A Windows PC or a Mac

Windows 10 or 11, 64-bit (Windows in S mode is not supported), or a Mac with Apple silicon or an Intel chip, on macOS 13 or later. About 2.5 GB of free disk space.

A Proffieboard

A V2.2 or a V3, in a saber or on the bench, and the installer's notes on how it is wired.

A USB data cable

Some cables only charge. If the saber is not seen, try another cable first.

What to expect

  1. 1

    Windows warns you

    The browser asks whether to keep the file, and SmartScreen shows a blue warning when you run it. The install guide shows each one and what to press.

  2. 2

    A one-time setup download

    The first build needs the compiler: about 360 MB, into Hiltwright's own folder. After that nothing more is downloaded.

  3. 3

    One driver approval

    The first install to a saber asks Windows for a USB driver, once. Then the tour in the app shows you around.

Build it from source

Hiltwright is licensed under GPL-3.0-or-later. The source for each release is tagged on GitHub. You need Node.js and git.

git clone {{repo}}.git
cd hiltwright
npm install
npm run dev     # run the app from source
npm run dist    # build the Windows installer

A build run from source this way is not blocked by Smart App Control.

Source on GitHub

Found a problem?

Press "Save diagnostics" in the app. It writes one file on your computer and sends nothing. Then open an issue on GitHub and attach that file.

Each report is answered: it is fixed, planned for a later release, or closed with a reason.
