Everything between a bare board and a finished saber.

Hiltwright has three parts. Install takes one saber from a plan to flashed firmware. Live changes a flashed saber that is plugged in, at once. The workshop is where you browse, build and try styles and fonts for any saber.

One saber, five numbered steps.

Armory

Every saber Hiltwright has seen is remembered, plugged in or not. Pick the one you are working on, then adjust it live or change its setup.

  • Plug a saber in with a USB data cable and it connects by itself.
  • "Change its setup" shows the five Install steps and how far this saber has got.
  • "New saber" plans one ahead: wiring, fonts, presets and styles, ready to flash. When the real saber is plugged in, Hiltwright asks whether it is the one you planned.
Armory in the docs

1 Wiring

Tell Hiltwright what is in the hilt: which Proffieboard, how many buttons, which prop file, and what each blade is wired to.

  • A blade is anything the saber lights or runs: main blade, crystal chamber, accent LED, motor.
  • The pin table shows which pins each blade uses, and any clash between them.
  • Nothing is installed until you confirm the wiring. A wrong power pin can damage hardware.
Wiring in the docs

2 Fonts

Choose the sound fonts the saber will carry, from your font library. Nothing is copied yet: that happens on the Card step.

  • Add a font package as you downloaded it, or a folder. Your originals are never changed.
  • Each chosen font says whether the card already has it, as last read.
  • With the Fett263 controls, choose the voice its menus speak in. A card whose voice pack is missing, too old or mixed with an older one is pointed out.
  • Six free ProffieOS fonts come with Hiltwright.
Fonts in the docs

3 Presets

A preset is one setup you switch to with the buttons: a sound font, a music track and a style for each blade.

  • The list waits in Hiltwright and goes on at the next flash. A copy of the saber's own presets is kept first.
  • If the saber was changed since your list was made, Hiltwright says so and offers to bring its presets in.
  • Save a whole preset list as a set, and load it on another saber.
Presets in the docs

4 Card

Sound fonts live on the saber's SD card. Put the card in a card reader and Hiltwright gets it ready in one go.

  • A card reader is about 30 times faster than the saber's own USB, which runs at USB 1.1 speed. The card is found as soon as it is in.
  • "Prepare the card" copies the chosen fonts it lacks, puts the voice pack on, and removes the old presets file so the new list takes effect.
  • Every font on the card is checked for the usual faults, such as a missing hum.
  • No card reader? "Share the saber's card" lends it over USB, more slowly.
Card in the docs

5 Build & Flash

This turns the wiring, presets and styles into firmware, and flashes it over USB.

  • The compiler is a one-time download of about 360 MB. After that a build takes about a minute.
  • The flash reads the saber's whole firmware into a backup file first.
  • Every backup is kept. "Put back" writes one onto the saber exactly as it was.
  • If a step fails, "Save diagnostics" writes one file to attach to a report.
Build & Flash in the docs

Live

For a saber that is already flashed and plugged in. Changes are written to the saber at once, with nothing built, and it works with any ProffieOS firmware.

  • Presets: change a font, a colour or a name, and see it saved when the saber reads it back. History undoes a change.
  • Controls: volume, brightness, effects and ProffieOS commands.
  • Card: a quick fix on the saber's card, such as one font or the voice pack.
Live in the docs

Styles and fonts, for any saber.

Styles

A style is what a blade does: its color, flicker, ignition, and how it reacts to clashes and swings.

  • Dozens of Hiltwright's own styles, for main blades, crystals, accents and motors.
  • The preview simulates the style LED by LED. Where it can only be approximate, a note says so.
  • Each style says whether it is on the saber, queued, or needs a build.
  • "Paste style code" takes a style from the Fett263 style library or anywhere else, with its credit.
Styles in the docs

Style editor

Build a style without writing ProffieOS style code.

  • Simple: a blade underneath, effects stacked on top, then the ignition and retraction.
  • Full: every ProffieOS layer. Pick a layer, then say what it shows, where on the blade, and when.
  • Open a Simple style in Full at any time.
  • "Save as a style" adds it to your Styles, ready for any preset.
The editor in the docs

Demo room

Try any style with any font on a saber in a dark room, before it goes near a real one.

  • Ignite with Space. Drag to swing, and scroll to twist the hilt.
  • Clash, blast, lockup, drag, melt, lightning block and special abilities, each with its key.
  • The sound follows ProffieOS: SmoothSwing, pre-on and post-off, begin and end sounds.
  • Load a preset from your saber: its style, colors and font, as they are on the saber.
The demo room in the docs

Font library and Contributors

Keep your sound fonts in one place on this computer, and see whose work you are using.

  • Add a font as you downloaded it (.zip), or as a folder. Your originals are left alone.
  • Play a font's sounds, note who made it, and copy it to a card.
  • Contributors lists font makers, style authors and hilt makers, each with a link.
The font library in the docs

Built so a mistake can be undone.

Backup before install

The saber's whole firmware is read into a file before anything is written. Putting it back is one button.

Wiring is confirmed

Nothing is installed until you have checked the pins and turned the confirm switch on. Any wiring change turns it off again.

Presets have a history

A copy of the saber's own presets is kept before staged ones replace them. Each restore lists what it will change first.

Fonts are checked

Before a build, Hiltwright warns if a preset names a font that is not on the card. Your original font files are never changed.

Risky commands ask first

In Diagnostics, a command that restarts the saber or changes its files asks before it is sent.

Diagnostics stay with you

"Save diagnostics" writes one file on your computer and sends nothing. You choose whether to attach it to a report.

Not in this beta.

  • Linux. This beta runs on Windows and, newly, on macOS.
  • On a Mac: installing firmware to a saber has not been confirmed yet, the six free sound fonts are not included, and the app does not update itself.
  • Code signing. Windows warns about the installer, and Smart App Control must be off.
  • Card formatting. Hiltwright warns about a card in the wrong format, but does not format it.
  • Blade ID and the Xenopixel import are hidden for now.

The full list is in the release notes.
